# HanMark 2.7.1 — Institution document workflow

HanMark 2.7.1 connects an institution's HWPX form to an editable Markdown note and makes the steps from template to exported official document easier to find. It runs inside desktop Obsidian 1.8.9 or later, offline and without AI tokens.

## What changed

- **Start with the right task:** use **기관 공문 작성** (Institution document) in the toolbar or command palette. Import an existing institution HWPX or create a new document from a registered form. When the open note is an unregistered template draft, the toolbar offers **기관 양식 등록** (Register institution template).
- **Keep the source editable:** an imported form becomes a Markdown draft. Review its text and images, then register its name, document type, organization, and approval line. An empty name is reported at the name field; the draft is not discarded.
- **Choose a form with context:** registered institution forms appear first in the template manager with their organization and document type. In official-document export, the note-linked institution form is named explicitly. If another form is selected, the window says so. Other output formats remain reachable from a collapsed format chooser.
- **Preserve existing documents:** new documents are separate notes; applying a form to an existing note leaves the body intact. Per-note choices do not switch the global template. HWPX, DOCX, HTML, and PDF continue through their existing export paths.
- **Dependency audit:** pinned transitive proxy-addr 2.0.8 after a new advisory; no server code is added to the desktop plugin bundle.

## Limits

- HWPX is the source format for making an institution template. Save an HWP file as HWPX in Hangul first. This release does not add HWP output, OCR, AI, fixed-position seal placement, or cloud sharing.
- The Markdown and semantic style model does not recreate every fixed-position drawing or field from the original HWPX. Check the generated HWPX in Hancom Office before submission.

## Verification

The release workflow runs the full test, TypeScript, bundle, Obsidian Community, and release checks across macOS, Windows, and Linux, plus browser UI and PDF smoke tests. The GitHub Release contains exactly `main.js`, `manifest.json`, and `styles.css`.
