# HanMark 2.7.1 — 기관 공문 작성 UI 개선 계획

- 작성일: 2026-10-06
- 대상: 데스크톱 Obsidian의 HanMark 2.7.0 기관 템플릿 기능
- 참고: Mobbin Square Templates(선택 분기), Dropbox Dash Creating a template(등록 확인), Notion Export a page(문서 맥락을 유지하는 내보내기). 화면 구조만 참고하고 타사의 화면·아이콘·소스는 복제하지 않는다.

## 사용자 목표와 범위

기관 HWPX를 가져온 사용자가 Markdown 초안을 수정하고 등록한 다음, 그 양식으로 공문을 작성·미리보기·HWPX 저장한다. 기존 문서에는 양식만 연결할 수 있다. 두 작업의 시작점을 한곳에 두고, 등록·내보내기에서 현재 상태가 보이도록 한다.

1. 툴바와 명령 팔레트에 **공문 작성**을 추가한다. 시작 창에서 **기관 HWPX 가져오기**와 **등록된 양식으로 새 공문**을 분리한다. 현재 노트가 등록 전 초안이면 **템플릿 등록**도 표시한다. 빈 목록에서는 가져오기만 제안한다.
2. HWPX에서 가져온 초안을 열면 계속 편집할 수 있게 하고, 툴바의 등록 동작으로 이름·문서 종류·기관·결재선을 확인한다. 빈 이름 오류는 그 필드에 연결한다. 클라우드 공유 권한처럼 이 플러그인에 없는 동작은 넣지 않는다.
3. 템플릿 관리 창에서 기관 양식을 먼저 보여주고, 이름·기관·문서 종류·상태와 새 문서 동작을 표시한다. 전역 HWPX 스타일 목록은 유지한다.
4. 공문 HWPX 내보내기에서는 노트에 연결된 기관 양식의 이름을 표시한다. 해당 노트가 없으면 기존 양식 선택 동작을 그대로 사용한다. 공문 모드에서는 파일 형식 카드가 양식 선택을 가리지 않도록 접을 수 있게 한다.

## 지켜야 할 계약

- 사용자 노트 본문, 기존 템플릿, 기존 명령 ID, 노트별 연결 및 전역 활성 양식은 이 UI 변경만으로 바뀌지 않는다.
- HWPX가 아닌 입력은 기존처럼 거절한다. `.hwp` 생성, AI 호출, OCR, 직인 좌표 조정, 팀 공유 기능을 추가하지 않는다.
- Obsidian의 `Modal`, `Setting`, 기본 버튼·테마 변수와 키보드 초점을 사용한다. 새 패키지나 외부 이미지, 네트워크 권한을 추가하지 않는다.
- 한국어·영어 메시지는 동일한 키로 제공하고, 좁은 창·명암 테마·키보드 사용을 확인한다.

## 수용 기준

1. 처음 사용하는 사람도 시작 창에서 두 경로를 구별하고, 등록된 양식이 없을 때 막다른 목록이 나오지 않는다.
2. 템플릿 초안을 연 동안 등록 동작이 보이며, 빈 이름은 입력란에 연결된 오류로 알리고 입력한 값은 잃지 않는다.
3. 등록된 양식으로 새 노트를 만들거나 기존 노트에 적용하면 그 노트의 공문 내보내기 창에 같은 양식명이 표시된다. 다른 노트의 전역 양식은 바뀌지 않는다.
4. HWPX 일반/공문, DOCX, HTML, PDF의 기존 내보내기 경로가 살아 있다. `npm run check`와 UI 스모크를 통과한다.
5. `main.js`, `manifest.json`, `styles.css`가 버전 `2.7.1` 태그의 GitHub Release에 올라가고 원격 자산을 읽어 검증한다. 공개 Obsidian Community 목록 갱신은 이 릴리스의 범위 밖이다.

## 순서

1. 기존 동작을 테스트로 고정하고 시작 창·등록 오류·양식 상태를 구현한다.
2. 관리자와 내보내기 화면의 순서를 다듬고 키보드·반응형 검증을 한다.
3. 버전·릴리스 노트·CI 태그를 갱신한 뒤 전체 검사, 원격 푸시, GitHub Release와 자산 검증을 한다.

실제 한컴오피스 렌더링은 별도 환경이 있어야 확인할 수 있다. UI 개선은 기존 HWPX 생성 경로를 바꾸지 않는다.
